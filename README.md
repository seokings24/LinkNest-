# LinkNest GitHub-ready PHP

No Login/Register. URL slug, title, photo preview, copy, open, delete, browser-private dashboard and public HTTP 301 redirect.

GitHub stores the source code. To RUN it, use PHP hosting with PDO SQLite and Apache/.htaccess support. GitHub Pages cannot execute PHP.

Upload the repository to GitHub, then deploy the repository to your PHP host. Make sure `data/` is writable.

The public redirect is `/go/example-link`.
